# Исходные данные

Скачайте [архив задания со Stepik](https://stepik.org/media/attachments/lesson/2589118/bot_detection_challenge.zip)
и разместите файлы относительно корня проекта:

```text
data/
├── train.csv
├── test.csv
└── events.csv.gz
sample_submission.csv
```

`sample_submission.csv` лежит в корне проекта и служит дополнительной проверкой
формата. Если его нет, решение всё равно выполняется.

| Файл | Содержимое | Строк |
| --- | --- | ---: |
| `train.csv` | Куки, границы окна и target | 11 091 |
| `test.csv` | Куки и границы окна без target | 4 909 |
| `events.csv.gz` | Журнал событий | 328 905 |

Данные не включены в архив проекта и исключены из Git через `.gitignore`.
Ноутбук читает только локальные файлы и не загружает их автоматически.
